Under The Hood

How the engine works.

Four simple steps from class name to rendered style.

1

Scan the DOM

After DOMContentLoaded, the engine queries all elements and reads their class lists.

2

Filter chai-* classes

Only classes starting with chai- are selected for processing.

3

Parse & match rules

The class name is stripped of the prefix and matched against a rules table to find the CSS property and value.

4

Apply & clean up

The computed style is applied as an inline style. The original chai-* class is removed from the element.

html
<!-- Before Chai CSS processes -->
<div class="chai-p-4 chai-bg-black
     chai-text-white chai-rounded-lg">
  Hello World
</div>

<!-- After Chai CSS processes -->
<div style="padding: 16px;
  background-color: #000;
  color: #fff;
  border-radius: 8px;">
  Hello World
</div>
Quick Start

Get started in 30 seconds.

1

Include the script

Add chai.js to your HTML file. No npm install required.

html
<script src="chai.js"></script>
2

Write utility classes

Use the chai-* prefix followed by any supported utility name.

html
<div class="chai-flex chai-items-center chai-gap-4">
  <h2 class="chai-text-2xl chai-font-bold">Title</h2>
  <p class="chai-text-gray chai-text-sm">Subtitle</p>
</div>
3

Open in browser

That's it. No build step, no configuration. Open the HTML file and your styles are applied.
